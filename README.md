## Building
This project was compiled using the [Raspberry Pi Pico](https://marketplace.visualstudio.com/items?itemName=raspberry-pi.raspberry-pi-pico) extension for Visual Studio Code. See the [Manual Compilation](#manual-compilation) section

### Requirements
- Raspberry Pi Pico W
- [pico-sdk](https://github.com/raspberrypi/pico-sdk)
- [Cmake](https://cmake.org/)
- [Make](https://www.gnu.org/software/make/) (if compiling without Raspberry Pi Pico extension)

### Visual Studio Code
You will first have to install Cmake. You can use your distribution's package manager if you are using a **Linux** environment. If you are on **Windows**, you can either download the Cmake binaries from the website or use a package manager like [Scoop](https://github.com/ScoopInstaller/Scoop).
